费时间的事，cx 可以交给帮手在后台去做，你和 cx 接着聊别的。cx 每交出一件事，看板的「帮手」页签上就有一张卡片，写着帮手的名字和它现在的状态；做完以后，cx 在对话里告诉你结果。适合一次查很多商品、做一大批对比这类要花时间的事。

帮手用命令生成的文件、抓取的网页和 cx 从数据源买的数据，不会列在卡片上；买数据的花费记在「设置」的「用量」里。

你可以这样问：

- 把这 20 个 ASIN 的竞品对比交给帮手，我们先聊别的。
- 交给帮手的那件事做完了吗？
- 把帮手查到的结果整理成一份报告。

## cx 的电脑关机时

如果帮手做完前 cx 的电脑关机，等电脑再开机，卡片上会写「cx 的电脑关机，已中断」。

## 费用

帮手和 cx 用同一个模型，从同一份余额付费。帮手做事时，cx 的电脑保持开机，开机时长照常计费。
