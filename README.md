cx can hand work that takes time to a helper in the background, while you and cx keep talking. Each job gets a card under Helpers on the board, with the helper's name and what it is doing now; when it is done, cx tells you the result in the conversation. Useful for checking many products at once or running a large comparison.

A card does not list files a helper writes with a command, pages a command fetches, or data bought with cx get; what the data cost is listed in Settings › Usage. While a helper works its card and its lists grow as files arrive, and the page does not keep your place as they do.

Some things you can ask:

- Hand the rival comparison for these 20 ASINs to a helper, and let's talk about something else.
- Is the job you gave the helper done yet?
- Turn what the helper found into a report.

## When cx's computer stops

If cx's computer stops before a helper is done, its card reads "Interrupted when cx's computer switched off" once the computer is back on.

## What it costs

Helpers use the same model as cx and are paid from the same balance. cx's computer stays on while a helper works, and that time is billed.
